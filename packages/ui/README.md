# @otwdesign/db-ui

OTW DB's browser app, prebuilt: the page, script and stylesheet `@otwdesign/db-core` serves, as one
module of strings. You don't use it directly; `@otwdesign/db-core` depends on it.

The app works the way TablePlus does: a connection list in environment colors, a sidebar of tables,
tabs, a fast grid with a filter bar, edits reviewed as SQL before they're committed, and a SQL
editor.

The whole guide: [github.com/OTWSRL/otw-db](https://github.com/OTWSRL/otw-db#readme).
